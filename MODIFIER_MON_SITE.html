Modifier mon site

Cette version a été préparée pour que vous puissiez modifier les contenus sans toucher au design.

Votre fonctionnement au quotidien

1
Ouvrez votre interface d'administration
Une fois le site connecté à GitHub, ouvrez Pages CMS.
2
Choisissez la page
Accueil, Séances, Accompagnements, Formations, À propos ou Contact.
3
Modifiez simplement
Changez un texte, un tarif ou une image dans un champ normal.
4
Enregistrez
La structure, les couleurs, les cartes et la mise en page ne bougent pas.
Ouvrir l'interface d'administration
Images pixelisées
Vous pourrez cliquer sur le champ de l'image concernée et importer une photo HD. Le site conservera automatiquement le même format et le même cadrage visuel.

La première connexion à GitHub est une configuration unique. Ensuite, vos modifications courantes se font uniquement dans l'interface visuelle.
